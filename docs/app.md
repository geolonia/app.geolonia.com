# Geolonia ダッシュボード仕様書
## 概要
Geoloniaの地図サービスを管理・設定するためのダッシュボードアプリケーションです。
## 主な機能
1. 認証機能  
[参照ソース](https://github.com/geolonia/app.geolonia.com/blob/develop/src/components/Signin.tsx)
- サインアップ/サインイン
- メールアドレス認証
- パスワードリセット
- 多言語対応(日本語/英語)

2. チーム管理  
[参照ソース](https://github.com/geolonia/app.geolonia.com/blob/develop/src/components/Team/Billing.tsx)
- チームの作成/編集/削除
- メンバー招待/権限管理
- 請求設定
- プラン変更

3. API キー管理
- APIキーの作成/編集/削除
- アクセス制御設定
- 利用制限の設定
- 使用状況の確認

4. データ管理
- GeoJSON/CSV/MBTilesファイルのアップロード
- データセットの作成/編集/削除
- 公開設定
- データのダウンロード

5. 使用状況モニタリング
- 地図表示回数の集計
- 料金の確認
- 使用状況のグラフ表示
- 制限超過の通知

### 多言語対応
- 日本語と英語に対応
- 言語ファイルによる管理
- ブラウザの言語設定に基づく自動切り替え

### チュートリアル/ヘルプ
- 初期設定ガイド
- API利用方法の説明
- カスタマイズオプションの解説
- サポート窓口へのリンク

### エラーハンドリング
- ユーザーフレンドリーなエラーメッセージ
- 多言語対応のエラー表示
- エラー状態の適切な管理
